Legacy quote scratchpad

The current 38-option budget is in the infrastructure options spreadsheet. Use its Infra Matrix and Infra Phase Budget tabs for current scenarios. This standalone scratchpad does not synchronize with that workbook.

Updated 24 September 2026. Enter written CAD quotes before tax. Use the published scenario totals as a starting point; add quoted services. No project duration is assumed.

Blank means quote required. Enter 0 only when a supplier includes or waives a charge. Equipment MSRP is not a monthly cloud rate. This compares cash spend, not depreciation.

Non-overlapping phase durations

Choose one starting or expanded configuration per period. Keep pilot preparation, live testing, closeout and post-pilot use in separate periods; do not add alternative configurations together. Include any minimum-term residual commitment exactly once.

Scope check

Align GPU/VRAM, CPU/RAM, Canadian facilities, network, disk, backup, licences, support, SLA and term. One-time amounts include CAPEX/activation and any residual contract liability. Metered amounts are total usage costs for the phase. Never treat an incomplete subtotal as cheaper.
