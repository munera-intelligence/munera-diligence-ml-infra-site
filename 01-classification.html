Fine-tuning method and initial hardware

GPU sizing arithmetic

Analytical sizing, not a measured peak or Daniel/security approval. Decimal GB = 10⁹ bytes; GiB = 2³⁰ bytes. Required device capacity is C ≥ (model state + saved activations + runtime workspace) / 0.8; leaving 20% free is our planning policy. Host RAM and disk cannot be added to VRAM without an explicit offload mechanism and performance trade-off.

The selected conservative mixed-precision Adam layout uses 18 bytes per trainable parameter: 2-byte compute weights + 4-byte master weights + 4-byte gradients + two 4-byte moments. Some implementations use 16 bytes instead; inspect the actual precision layout. For adapters, our 18-byte allowance is FP32 parameters/gradients/Adam (16 bytes) plus a possible 2-byte compute copy; PEFT can compute directly with FP32 adapters, so that copy is not guaranteed residency. PEFT dtype guidance. Frozen BF16 base weights use 2 bytes/parameter and have no base gradients/Adam state. LoRA state is base bytes + 18 × trainable adapter parameters. Memory accounting, LoRA parameters.

For a classic transformer encoder, the published saved-activation reference is A = L × S × B × H × (34 + 5 × heads × S / H) bytes: layers L, sequence tokens S, device microbatch B and hidden width H. This is the paper's 16-bit MHA, 4H/GELU MLP, non-checkpointed reference, not an exact allocator trace; classifier/output buffers and kernels remain outside it. MLSys 2023 equation 1.

Munera workflow and maturity

The following is the documented target workflow, not an implementation audit: reviewed correction data → versioned dataset → validation/preparation → classifier training → frozen evaluation → human approval → registered version → deployment → quality feedback. Airflow owns ML orchestration; Temporal remains the application's workflow engine. DVC holds dataset lineage; MLflow records runs and model versions. Munera design, §2–4

Published experience

  • Meta research: XLM-R was evaluated on cross-lingual classification, sequence labelling and question answering. This establishes multilingual encoder evidence, not Québec construction-document accuracy. Original XLM-R paper
  • Inria research: CamemBERTav2 reports French sentiment, paraphrase and inference benchmarks, plus biomedical entity extraction. These are distinct supervised datasets, not Munera's phase/type taxonomy. CamemBERT 2.0 paper
  • Sheffield/VeraAI research: the SemEval submission used an XLM-R-large ensemble with adapters for multilingual news framing. This is an alternative published adaptation method, not evidence that Munera has selected or reproduced it. Task report

Before production approval: confirm taxonomy, language distribution, corpus size, accuracy/abstention and latency targets. Validate peak VRAM/RAM, checkpoint save/load and a representative epoch against the proposed allocation; schedule the larger shared GPU if the L4 pilot fails. These acceptance inputs refine the explicit pilot budget above. Shared services are in infrastructure; priced machines and quote gaps are in pricing.
